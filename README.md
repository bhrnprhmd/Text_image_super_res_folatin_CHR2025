# Text_image_super_res_folatin_CHR2025
Repository related to the paper "Blind Text Super-resolution for Enhancing the Readability of Hidden Fragments" presented at CHR 2025. 
You can access the weights from: https://drive.google.com/drive/folders/13KePwDnvHNm-wquwWsVJNfnoXedX0rsG?usp=sharing

This work is part of the project “AntCom: From Antiquity to Community.” The AntCom project
has received funding from the European Union’s Horizon 2021 research and innovation programme
under the Marie Sklodowska-Curie grant agreement No 101073543.
